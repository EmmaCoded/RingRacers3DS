# Tools (`tools/`)

## Build
| File | Purpose |
|---|---|
| `build3ds.sh` | Configure and build the `.3dsx` inside devkitPro's MSYS2; bumps the automatic `1.0.N` version |
| `../install_devkitpro.sh` | Installs the devkitPro packages the port needs |

## Asset pipeline (your game folder -> SD card)
| File | Purpose |
|---|---|
| `prepare_3ds.py` | Runs the whole pipeline; drag a mod `.pk3` onto it to convert only mods |
| `make_patch3ds.py` | Bundles the pipeline into one `prepare_3ds.exe` with PyInstaller |
| `extract_defs.py` | Extracts the texture/sprite definitions the converters need |
| `convert_textures.py`, `convert_etc1.py`, `convert_etcpal.py`, `convert_small.py`, `convert_tweakmap.py` | World textures to ETC1 (including custom-palette maps and the small-texture pack) |
| `convert_sprites.py`, `convert_atlas.py` + `atlas_list.txt`, `make_atlas.bat` | Sprites to ETC1A4 and the fixed object atlas |
| `make_thumbnails.py` | 80x50 map thumbnails (`thumbnails_3ds.bin`) so the menu does not render maps |
| `convert_audio.py`, `dspenc.c` | Effects/music to DSP-ADPCM (`RRS2`, `RRM2`/`RRMM`); tracker music through `openmpt123` |
| `convert_chars.py` / `.bat` | The 63 vanilla characters as lazily mounted packs |
| `convert_mod.py` / `.bat` | Character mods (skins with voices), repacked uncompressed |
| `preload lists` | Generated by the game while racing (`cache/pre`); `make_preload_lists.py` pre-generates them in the emulator |

## Runtime data the game reads
`ringracers_3ds_etc.bin`, `ringracers_3ds_spr.bin`, `ringracers_3ds_atlas.bin`, `ringracers_3ds_small.bin`,
`thumbnails_3ds.bin` and the `cache/` folder (`.rr3` map packages, `.rrv` visibility, blend tables, palettes).

## Developer harness (emulator)
These scripts drive Azahar for repeatable measurements and contain machine-specific paths at the top of each file:
`rrbench.py` (build, configure the emulator, run N races, average, detect crashes), `worst_maps.py` /
`worst_powerbi.py` (worst case per map to CSV), `prof_resolver.py` (resolve the `RR_PROF` profile), `gdb3ds.bat`
(GDB over Wi-Fi with the Luma debugger).
